# Analytics Desk

Веб-платформа автоматизации аналитической работы управления превенции и аналитических разработок.

## Возможности MVP

- Авторизация и роли (аналитик, старший аналитик, руководитель, администратор)
- Реестр дел и карточка дела
- Загрузка Excel / CSV / XLS выгрузок ЭСФ
- Автоматическое сопоставление колонок и валидация
- Разделение приобретения и реализации
- Сопоставление товарных позиций (точное + fuzzy)
- Расчёт разницы цен и количеств
- Аналитические сигналы (отклонения цен)
- Формирование черновика аналитической справки в Word
- Журнал действий

## Быстрый старт

```bash
cd analytics-desk
docker compose up --build
```

После запуска:

- Frontend: http://localhost:3000
- Backend API: http://localhost:5000/api/health
- Демо-пользователи:
  - `analyst@analytics.local` / `analyst123`
  - `admin@analytics.local` / `admin123`

## Сценарий работы

1. Войти под analyst
2. Создать дело (или открыть демо AD-2026-0001)
3. Вкладка «Файлы» → загрузить Excel/CSV с колонками ЭСФ
4. Подтвердить сопоставление колонок → «Запустить обработку»
5. Вкладки «Приобретение» / «Реализация» — просмотр позиций
6. «Сопоставление» → «Запустить сопоставление» → подтвердить/отклонить
7. «Справка» → сформировать и скачать Word

## Безопасность

- JWT-авторизация, проверка прав на сервере
- Пароли хешируются bcrypt
- Загружаемые файлы не исполняются (макросы отключены)
- Оригиналы файлов сохраняются с SHA-256
- Все значимые действия пишутся в audit_logs
- Не размещайте реальные служебные данные в публичных окружениях

## Модуль «Связи» и госзакупки

- Вкладка **Связи** в карточке дела: граф Cytoscape (ЭСФ + договоры + ручные связи).
- Риски: K_gos, концентрация заказчика, эвристика «нет МТБ».
- Синхронизация OWS: задайте токен в окружении:

```bash
export GOSZAKUP_API_TOKEN=ваш_bearer_токен
# или в .env рядом с docker-compose
docker compose up --build
```

Токен **не** храните в git. Документация API: https://goszakup.gov.kz/ru/developer/ows_v3
